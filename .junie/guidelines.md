# Project Guidelines

## Design Principles

- **Mobile-First Focus**: The main and first focus of the design should be mobile view. All components and layouts must be optimized for mobile devices before considering larger screens.
- **Light and Dark Mode Support**: The application must support both light and dark modes. Default mode should follow user system preferences.
- **Background Colors**: In dark mode, the main background color must be Tailwind's `bg-slate-950` (or `oklch(0.129 0.042 264.695)`). In light mode, it should use a standard light background.
